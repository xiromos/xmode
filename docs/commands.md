# Commands

### Standard
**help**: show available commands<br>
**clear**: clear screen<br>
**mmap**: shows memory map + available memory<br>
**pci**: shows all PCI devices<br>
**usb**: shows all connected USB devices<br>

### Filesystem
**ls**: list content of current directory<br>
**read**: print file<br>
**write**: create file<br>
**rename**: rename a file<br>
**del**: delete a file<br>
**cd**: change directory<br>
**cdisk**: switch drive<br>
**lsdisk**: lists all available drives and general information about them<br>

### Customization
**bgcolor**: change background color of terminal (usage: 'bgcolor #RRGGBB')<br>

### Multitasking
**tasklist**: list all running tasks
**taskkill**: kill a task (usage: 'taskkill window.obj')

### Network
**dhcp**: start DHCP Client to get connected to internet<br>
